# 蜂宅 CRM・報價（前端）

靜態網頁前端，資料都在 Google 試算表，透過 Apps Script 網頁應用程式 API 讀寫，需要密碼登入。
這個 repo 只有畫面程式碼，不含任何客戶資料或密碼。

## 各工程報價

案件頁以工程卡片分開顯示木作、水電等工程的項目數與小計。各工程可獨立新增、修改、列印；手機版使用逐項欄位，整案總額與整案報價單仍可查看。

沿用既有 Apps Script API 與試算表欄位，不需要重新部署後端。儲存某工程時，會重新讀取最新整案、保留其他工程，並建立整案草稿版本；已送出或已簽約的舊版本保留於「整案報價歷史」。報價狀態、版本編號及合約／工期引用仍屬於整案，並非每個工程各有一個後端報價 ID。

儲存前若發現同工程內容已變動，會停止儲存並保留編輯畫面。現有後端沒有條件式寫入／版本鎖 API，因此無法保證兩台裝置在最後讀取與寫入之間同時儲存時的原子性；多人高頻共同編輯需後續配合後端鎖定。

以 `node tests/verify-quotes.cjs` 執行虛構資料測試，涵蓋單工程編輯、其他工程合併、同名品項、衝突提示、重複送出、單工程／整案列印及儲存失敗重試。
